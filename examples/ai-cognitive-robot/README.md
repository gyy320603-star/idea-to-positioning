## The 30% threshold

The decision brief uses a **30% adherence improvement** as a proposed test threshold. It is not a validated result.

- **Comparator:** a sticky note / browser prompt that says “write your first answer before asking AI”.
- **Metric:** first-answer-before-AI **rate** = events ÷ eligible AI queries in the week; report both count and rate.
- **Calculation:** `(B − A) / A ≥ 0.30` when A > 0. If A = 0, report the percentage-point difference instead; a relative threshold is undefined at zero.
- **Status:** proposed; to be tested over two weeks with 8–10 AI-heavy users.

If B does not clear 30% relative (or the agreed percentage-point difference when A = 0), the example recommends removing the robot body and keeping the “think-first” ritual in software or paper.
