# Idea to Positioning

Use this skill for early-stage brand, product, and coursework decisions. It works from a topic, a scene or audience hypothesis, or an existing concept. Visual identity, production CAD, and media buying come after positioning.

## Choose the request mode

| User request | Procedure | Deliverable |
|---|---|---|
| Position a topic or hypothesis (default) | Follow the [workflow](references/workflow.md). When starting with a topic, hypothesis, or links, use the [minimal-input research guide](references/minimal-input-mode.md). | Decision brief, eight-page outline, grill log, source table, and appendix. |
| Explicitly asks for one page | Apply the same positioning and evidence criteria in the [workflow](references/workflow.md). Skip the deck. | One-page decision brief and source table. |
| Grill an existing claim, concept, or deck | Go directly to the [grill protocol](references/grill-protocol.md). Open with the strongest disconfirming question. | One-page grill log. Review a deck if supplied. Create a deck only on explicit request. |
| Run multiple batches on one topic | Use the [campaign guide](references/long-run-mode.md) for batch sizes, screening, blind review, and human checkpoints. | Campaign records, funnel counts, and finalists. |

For a student or other non-AI reader, use the [front-stage guide](references/front-stage-output.md) to present the selected package. Course requirements change its contents. The requested mode still determines its scope.

Use the [output paths](references/outputs.md) for the selected mode. Read packaged templates as inputs. Fill a copy in the user's project at the specified output path. Keep examples and templates in the skill directory available for the next run.

## Shared decisions

- Start with the category, scene, assignment or business constraints, known evaluation criteria and deadline. Distinguish group decisions from agent assumptions. A topic alone suffices. Use supplied links first and ask at most one clarification when ambiguity would change the frame.
- Compare a portfolio of directions to the cheapest existing substitute. Identify a decision-changing constraint through an observed choice of time, place, object, or behaviour. A missing feature alone establishes no demand.
- Define the audience by behaviour, relationship, occasion, and frequency. In a two-person occasion, distinguish the initiator from the companion. Keep one value promise, with the slogan separate.
- Code evidence using the [evidence guide](references/evidence-coding.md). Match each claim to what its source can support, retain counterexamples, and label unverified claims. Never fabricate interviews, prices, sales, market share, or quotes. Use the [research thresholds](references/minimal-input-mode.md#research-budget) when screening or substantiating a key claim.
- Let the claim survive review before investing in a deck, visual identity, packaging, or campaign execution. A grill ends in a decision and records what changed.
- For 《品牌策略与设计管理》 coursework, load `brand-strategy-course-project` if installed. Follow the B p47 / A p27 anchors and [course canvas mapping](references/positioning-canvas.md#course-mode-mapping). The instructor may set a different page count or pitch length.

## Handoff

Lead with a one-sentence verdict or current-gate judgment. Use a table or numbered steps to connect each output to its gate. End with one concrete next action and the project file path. For a grill, identify the minimum evidence needed next. For a campaign, report the current phase and funnel counts, and wait for blind review before naming a winner. For a front-stage delivery, use the guide's chat-style opening.

The [worked example](examples/ai-cognitive-robot/README.md) shows a topic-only run and a proposed test threshold.
