# Deck Outline

Default 8-page stage-one deck for a **full-positioning** request. Do not use this for a single grill request; a grill-only request stops at the grill log. Each page answers one question.

| Page | Question | Content | Rule |
|---|---|---|---|
| P1 | What is this? | Brand, one-line promise, invitation | Do not put a spec sheet on the cover. |
| P2 | Why this scene? | Track, rule/constraint, boundary | One rule, one date, one source. |
| P3 | Who is it for? | Behaviours, pains, initiator/companion | No demographic-only persona. |
| P4 | What is the promise? | Who / What / How | What <=15 chars in course mode; slogan separate. |
| P5 | Is it a brand? | Six dimensions / brand idea | All six return to the same promise. |
| P6 | Why you? | 3 competitors + SWOT + real substitutes | Prices with source and date. |
| P7 | Where does it fail? | Journey + weakest touchpoint | Name one weak moment and the fix. |
| P8 | What next? | Business model, brand assets, validation | Three tests, one decision rule. |

## Page rules

- One page, one question.
- Every claim carries a label: `[observed]`, `[self-report]`, `[inferred]`, `[assumption]`.
- No absolute claims from a limited search.
- Do not put a product feature on P3 unless it is tied to a behaviour.
- Do not put a slogan in the What slot.
- Put `known unknowns` on P8; do not hide them.
- The 3-minute script lives in speaker notes, not on the slide.

## 3-minute script shape

| Time | Page | What to say |
|---|---|---|
| 0:00–0:15 | P1 | Name, promise, invitation. |
| 0:15–0:40 | P2 | The constraint and why this scene. |
| 0:40–1:10 | P3 | The initiator, the companion, the three behaviours. |
| 1:10–1:35 | P4 | Who / What / How; read the invitation. |
| 1:35–2:00 | P5 | Six dimensions in one breath. |
| 2:00–2:30 | P6 | Three competitors, one gap, one caveat. |
| 2:30–2:50 | P7 | The weakest moment and the fix. |
| 2:50–3:00 | P8 | The next test, not a summary. |

## Course mode

A p27 requires: persona (3 tags + 3 pains), 2W1H, honeycomb, name + slogan. A p36/p53 add competitors + SWOT. The user journey, 8 pages, and 3 minutes are our packaging choices unless the instructor says otherwise. Cite the page anchors in the deck's source notes.

## General mode

Default 8 pages. Use a one-page brief only when the user explicitly asks for one page; do not turn a one-page request into an 8-page outline. Replace the honeycomb with a brand idea / proof page if the project is not coursework. Keep the same rule: one promise, one gap, one weakest touchpoint, one next test.
