# Project outputs

Use this table when writing project files. `Template` is a read-only input relative to the installed skill. `Project path` is relative to the current project's output directory, outside the installed skill. Render a fresh copy there. An em dash means the workflow supplies the content without a file template. The project may choose its output directory.

Select the rows for the requested mode. A single grill produces one page. A one-page request produces the decision brief and its source table. A full run uses the four delivery files, five appendices and the gate notes under `work/`. The appendices summarize the working notes. The full grill log is the delivery version of the Gate 8 decision. A campaign keeps its own working tree as described in [long-run mode](long-run-mode.md).

For a student-facing full run, use the front-stage delivery files and retain the working evidence under `work/`. The idea appendix PDF is optional. The listed PDFs are the default filenames; if the requester selects slides, use the corresponding PPTX format and update the reading links. In the reading guide link only to artifacts actually delivered. Existing exports may have an appendix beside the delivery directory; leave existing files in place when reading an earlier project.
