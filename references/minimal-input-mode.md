# Minimal Input Mode

Use this when the user gives only a topic, or a topic plus a scene/persona hypothesis. The agent supplies the research, not the user.

## Input tiers

| Tier | User gives | Agent does |
|---|---|---|
| 1 | Topic only | Public scan, 2–3 candidate frames, pick the strongest, list runners-up. |
| 2 | Topic + scene/persona | Treat the hypothesis as `[assumption]`; test it; keep, narrow, or reject. |
| 3 | Topic + links | Use the links first, supplement, record dates. |

A topic suffices to start. Evaluation criteria, group decisions, and links can be added when available.

## Default behaviour

- Work in **provisional mode**: choose a frame, say why, and write what would change it.
- If the topic is genuinely ambiguous, ask one clarification; otherwise proceed with labelled assumptions.
- If the user gives a hypothesis, do not flatter it. Test it against public evidence.
- If the evidence is thin, say so; do not write a confident deck.

## Research budget

- 8–15 searches.
- 6–10 extracted sources.
- Screening threshold: two independent sources that agree can advance a concept to the next gate.
- Key-claim threshold: a key claim needs three independent sources, including at least one non-self-report source (official rule, product page, observed behaviour, or dated first-hand account). Fewer than three → label `[assumption]` or `[self-report]`.
- If three sources conflict, report the conflict rather than averaging it; do not stop at a false consensus.
- Prefer official rules, product pages, dated posts, and reviews over content farms.
- Record URL, access date, type, confidence, and counterexample.

## Search lenses

| Lens | Example query pattern |
|---|---|
| Rules | `<city> 公园 帐篷 地钉 风绳 规定` |
| Category | `<product> 价格 评测 缺点` |
| Behaviour | `<scene> 带什么 怎么吃 怎么收` |
| Relationship | `找搭子 / 和朋友 / 家庭 野餐` |
| Counterexample | `<scene> 不需要 / 不用 / 取消` |
| Competitor | `<brand> <model> 价格` |

## Source hierarchy

1. Official rule text, product page, or price page.
2. Dated public post with photos or a first-person account.
3. Review / comment with a concrete use detail.
4. Aggregator or content farm (use only as a lead, not as proof).

## No-evidence rule

If a search returns nothing usable:

- write `[not found]`;
- say what you searched;
- propose the cheapest next check;
- do not invent an interview, a price, or a quote.

## When to stop and ask

Ask one question only if the answer changes the frame:

- Is this a course assignment or a commercial project?
- Is the topic the product category or the brand?
- Is there a hard constraint (budget, size, regulation)?

Otherwise proceed and mark the assumption.
